# BACKSHOT

A static splash page for the Sheffield punk band. Open `docs/index.html` directly or serve `docs/` with a static web server. No build step or external assets.

The band-supplied wall photograph is the only artwork. Edit the biography and social links in `docs/index.html` and the layout and light effect in `docs/style.css`.

When material is ready, add an About section, live and behind-the-scenes photos, a Bandcamp embed for the EP, and confirmed shows.
